# SIMRS RS Suka Sehat - Week 7

Prototype statis HTML/CSS/JavaScript untuk demonstrasi Login + RBAC dan UI modul:
- Laboratory
- Pharmacy
- Scheduling & Appointment

## Menjalankan
Buka `index.html` di browser.

## Akun demo
- Laboratory: `laboran` / `123456`
- Pharmacy: `apoteker` / `123456`
- Scheduling: `registrasi` / `123456`

Pilih role yang sama dengan akun saat login.

## Catatan
UI dibuat mengikuti PDF referensi yang diberikan. Data adalah data dummy untuk kebutuhan demo Week 7.
