PANDUAN ONLINE DI VERCEL — SIMRS RS SUKA SEHAT
==============================================
Total waktu kira-kira 20–30 menit. Semua layanan di bawah GRATIS (tanpa kartu kredit).

Gambaran:
  GitHub (kode)  ->  Vercel (menjalankan PHP)  ->  TiDB Cloud (database MySQL online)


BAGIAN A — MASUKKAN FILE VERCEL KE REPO GITHUB
1. Ekstrak file UPDATE_VERCEL.zip.
2. Buka folder hasil ekstrak -> masuk ke folder SIMRS_UPDATE_VERCEL -> tekan Ctrl + A -> Ctrl + C.
3. Buka folder repo:  C:\xampp\htdocs\simrs-suka-sehat-final  -> Ctrl + V.
   Jika ditanya, pilih "Replace the files in the destination".
4. Buka GitHub Desktop (repo simrs-suka-sehat-final) -> akan muncul beberapa changed files
   (vercel.json, api\index.php, setup.php, file.php, config\..., includes\..., pages\radiologi.php).
5. Summary: "Siapkan Vercel" -> Commit to main -> Push origin.


BAGIAN B — BUAT DATABASE ONLINE (TiDB Cloud)
1. Buka https://tidbcloud.com -> Sign up (boleh pakai akun Google / GitHub).
2. Buat cluster gratis:
   - Pilih paket "Starter" (gratis).
   - Cloud provider: AWS, Region: Singapore (ap-southeast-1)  <- penting, dekat dengan Vercel.
   - Nama cluster bebas, mis. simrs  -> Create.
3. Setelah cluster jadi, klik cluster -> tombol "Connect" (kanan atas).
   - Connect With: "General" (atau pilihan yang menampilkan Host/Port/User).
   - Klik "Generate Password" -> SALIN dan SIMPAN password-nya (hanya ditampilkan sekali).
   - Catat:  HOST  (mis. gateway01.ap-southeast-1.prod.aws.tidbcloud.com)
             PORT  (4000)
             USER  (mis. 2abcDEF123.root)
             PASSWORD (yang baru di-generate)


BAGIAN C — DEPLOY DI VERCEL
1. Buka https://vercel.com -> Sign up / Log in dengan GitHub (akun pemilik repo).
2. Klik "Add New..." -> "Project".
3. Cari repo "simrs-suka-sehat-final" -> klik "Import".
   (Jika repo tidak muncul: klik "Adjust GitHub App Permissions" lalu izinkan repo tersebut.)
4. Framework Preset: "Other". Root Directory, Build & Output Settings: BIARKAN DEFAULT.
5. Buka bagian "Environment Variables", tambahkan satu per satu (Key = Value):
     SIMRS_DB_HOST    = HOST dari TiDB
     SIMRS_DB_PORT    = 4000
     SIMRS_DB_USER    = USER dari TiDB (lengkap dengan awalan, mis. 2abcDEF123.root)
     SIMRS_DB_PASS    = PASSWORD dari TiDB
     SIMRS_DB_NAME    = simrs_suka_sehat
     SIMRS_SETUP_KEY  = buat kata kunci sendiri, minimal 6 karakter (mis. sukasehat2026)
6. Klik "Deploy" dan tunggu sampai muncul "Congratulations" (1–3 menit).
7. Klik gambar website / "Continue to Dashboard" -> salin alamatnya, mis.
   https://simrs-suka-sehat-final.vercel.app


BAGIAN D — ISI DATABASE (sekali saja)
1. Buka:  https://ALAMAT-VERCEL-KAMU/setup.php
2. Masukkan kunci setup (sama dengan SIMRS_SETUP_KEY) -> Lanjut.
3. Pastikan tertulis "SSL: Aktif" dan tidak ada pesan error koneksi.
4. Klik "Install / Isi Database" -> tunggu sampai muncul "Berhasil! ... Database siap dipakai."
5. Klik "Buka halaman login" -> login admin / admin123 (akun lain ada di README.txt).

Selesai! Link Vercel bisa dibagikan ke dosen.


JIKA ADA MASALAH
- setup.php menulis "Halaman setup belum aktif"
    -> SIMRS_SETUP_KEY belum diisi. Isi di Vercel -> Project -> Settings -> Environment Variables,
       lalu Deployments -> titik tiga pada deployment teratas -> Redeploy.
- "Tidak bisa terhubung ke database"
    -> cek lagi HOST / USER / PASSWORD (tanpa spasi di awal/akhir). Setelah mengubah
       Environment Variable WAJIB Redeploy.
- Halaman login menulis "Database belum terhubung"
    -> sama seperti di atas, atau Bagian D belum dijalankan.
- Ingin mengulang data dari awal (mis. sebelum presentasi)
    -> buka setup.php, centang "Hapus dan isi ulang dengan data contoh", klik Install.
- Setiap kali ada perubahan kode: Commit + Push di GitHub Desktop -> Vercel otomatis deploy ulang.

CATATAN TEKNIS (untuk dosen / penguji)
- Runtime PHP 8.3 (vercel-php@0.7.4), semua request .php diarahkan ke api/index.php
  (front controller) yang menjalankan halaman aslinya. Folder config/, includes/, database/
  tidak bisa dibuka dari browser.
- Sesi login disimpan di tabel app_sessions karena server Vercel tidak punya penyimpanan file
  permanen; gambar radiologi yang diunggah disimpan di tabel app_files (maks. 4 MB).
- Koneksi database memakai SSL dengan verifikasi sertifikat (config/cacert.pem).
- Versi XAMPP tetap berjalan seperti biasa (file-file di atas tidak dipakai di XAMPP).
